# وسيط IslamQA

وسيط Cloudflare صغير يسمح لتطبيق «تدبّر» بقراءة واجهة `islamqa.info` من المتصفح.

الموقع يوفّر JSON عاماً للبحث عن الإجابات، لكنه لا يرسل ترويسة `Access-Control-Allow-Origin`، فلا يمكن لتطبيق مستضاف على نطاق آخر قراءته مباشرة. هذا العامل يقرأ الواجهة من الخادم ويعيد النتائج مع CORS.

## النشر

من هذا المجلد:

```sh
npm install -g wrangler   # إن لم يكن مثبّتاً
wrangler login
wrangler deploy
```

الرابط المنشور حالياً هو `https://tadabbur-islamqa.bnanbrand.workers.dev`، وهو الافتراضي في الإنتاج والتطبيق الأصلي.

يمكن تجاوزه في إعدادات البناء إن لزم:

```sh
VITE_ISLAMQA_WORKER_URL=https://tadabbur-islamqa.<حسابك>.workers.dev
```

أو في ملف `.env` محلياً للتطوير. إن تُرك المتغير فارغاً، يستخدم التطبيق وكيل Vite المحلي `/islamqa-api` أثناء `npm run dev`، والوسيط المنشور بعد البناء.

## ما يعيده العامل

- `GET /health` — فحص بسيط.
- `GET /?q=حكم الغيبة` — يعيد حتى ٦ إجابات من `islamqa.info`، كل واحدة بعنوان السؤال ونصّه ونصّ الجواب ورابط المادة.

لا يُنشئ العامل جواباً ولا يستخدم نموذجاً لغوياً؛ النصوص منقولة كما نشرها الموقع، وتُخزَّن ٢٤ ساعة في حافة Cloudflare.
