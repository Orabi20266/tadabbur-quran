# تدبّر — نسخة تعلّم لحلقة حفظ القرآن

**استخدام مباشر:** <https://orabi20266.github.io/tadabbur-quran/>

تطبيق ويب/PWA يقلّد **حلقة الحفظ الأساسية**: إخفاء الآيات، التلاوة من الذاكرة،
تتبّع الكلمات أثناء القراءة، تعليم الأخطاء، وسجلّ لكل كلمة. واجهة عربية RTL
تعمل دون اتصال بعد أول تحميل.

> نسخة تعلّم شخصية، مكتوبة من الصفر. لا تستخدم أي كود أو أصول أو علامة تجارية
> أو نموذج صوتي من تطبيقات تجارية. نص القرآن من `quran-json` (Tanzil، CC-BY-4.0).

## التشغيل

```bash
git clone https://github.com/Orabi20266/tadabbur-quran.git
cd tadabbur-quran
npm install
npm run dev      # http://127.0.0.1:5174
npm test         # اختبارات الوحدة (quran + المواءمة + المؤشر + VAD + المحاكاة)
npm run build    # فحص الأنواع + بناء الإنتاج + Service Worker
npm run preview  # معاينة build
./scripts/package-desktop.sh  # حزمة تدبّر.app على سطح المكتب
```

المتطلبات: Node ≥ 20. إن ظهر تحذير `install-scripts` في npm، فالحزم المطلوبة
مسجّلة في `allowScripts` داخل `package.json`.

## المسارات

| المسار | الصفحة |
| --- | --- |
| `/` | الرئيسية: السلسلة، هدف اليوم، نقاط المراجعة |
| `/read/:surah?ayah=N` | المصحف + جلسة التتبّع (`?session=1` يبدأ تلقائياً) |
| `/memorize` | خريطة الحفظ: تعليم الآيات لكل سورة |
| `/tajweed` | أسئلة اختيار من متعدد في أحكام التجويد مع الشرح |
| `/hadith` | موسوعة أحاديث صحيحة مختارة من الدرر السنية |
| `/activity` | الجلسات والأخطاء (إزالة/إرجاع) |
| `/settings` | السمة، حجم الخط، كشف الأخطاء، التصدير/الاستيراد |
| `/onboarding` | أول تشغيل: البداية والهدف |

التوجيه عبر `HashRouter` حتى يعمل النشر الساكن من أي مسار دون إعداد إعادة كتابة.

## البيانات

كل شيء في `localStorage` تحت المفتاح `tadabbur.v1`:

```
settings, sessions, mistakes, wordStats, marks, daily, streak, lastRead
```

- **تصدير/استيراد**: من الإعدادات ← بياناتك.
- **إعادة الضبط**: تحذف كل السجل والعلامات على هذا الجهاز.
- السجل يحفظ أيضاً الجلسة إذا غادرت الصفحة أثناء التلاوة (يُحفظ ما أُتمّ).
- مفاتيح مستقلة: `tadabbur.tajweed.v1` لنتائج التجويد، و`tadabbur.hadith.v1`
  لمحفوظات الحديث.

## محرّك التتبّع

`src/lib/useSpeech.ts` يغلّف `SpeechRecognition` في المتصفح (`ar-SA`) ويمرّر
الكلمات المستقرّة فقط من النص المتعرَّف عليه. `src/lib/align.ts` يطابقها مع
كلمات الآية (تطبيع، مسافة تحرير، دمج كلمتين، تخطّي/تكرار)، و`src/lib/tracker.ts`
يحرّك المؤشر. لا يوجد مؤقّت ولا مستوى صوت وهمي: الصمت لا يقدّم شيئاً، والكلمة
لا تُفتح إلا عندما يسمعها المحرّك أو عندما تضغط **«الكلمة التالية»**.

### كيف تُطابَق الكلمات

- **تطبيع النص العثماني:** الألف الخنجرية (U+0670) في «ٱلصِّرَٰطَ» و«ٱلۡعَٰلَمِينَ»
  تُعامَل ألفًا مكتوبة، لا حركة تُحذف؛ وإلا صار النص «الصرط» فبدا «الصراط»
  كلمةً أخرى. الهمزة المفردة تُحذف، وأشكال الألف والياء والتاء المربوطة تُوحَّد.
- **مسافة تحرير مرجّحة:** إضافة/حذف حرف مدّ (ا/و/ي) أو خلط معروف بين حروف
  متقاربة صوتًا (ق/ك، ص/س/ث، ض/ظ/ذ/ز، ط/ت) يُحسب تشويشًا صغيرًا لا خطأً، بشرط
  اتفاق الحرف الأول. المتعرّف ليس نموذجًا مدرَّبًا على التلاوة، وهذه الأخطاء
  هي أكثر ما ينتجه.
- **التنوين والحروف الملتصقة:** «كأساً» تُسمع «كأس» بلا ألف ولا تنوين، و«وكأساً»
  قد تُسمع «كأس» بلا واو؛ كلاهما يُقبل إذا بقي أصل الكلمة. وكذلك تُقبل الواو أو
  الفاء أو الباء أو اللام أو الكاف الملتصقة إذا حُذفت أو زيدت في كلمة طويلة
  بما يكفي — أما الكلمات القصيرة مثل «ولم» و«وما» فتبقى صارمة لأن حذف الواو
  منها يصنع كلمة أخرى.
- **إدغام النون وإقلابها:** عند تطبيق الأحكام تُنطق نون «مِن» و«أَن» متجانسة مع
  الحرف التالي أو ميمًا («مِن رَّبِّكَ» → «مر ربك»، «مِن بَعۡدِ» → «مم بعد»)،
  فيُقبل اختلاف الحرف الأخير وحده عندما يكون من حروف الإدغام. لا يُقبل غير ذلك،
  فالكلمة المختلفة تبقى خطأً.
- **دمج الجزيئات:** إذا فصل المحرّك واو العطف أو الباء أو الفاء («و الله»)،
  تُدمج قبل التتبّع («والله») ولا تُحسب كلمة مستقلة.
- **البسملة والاستعاذة قبل أول كلمة:** ما يقوله القارئ قبل بدء الصفحة —
  «أعوذ بالله»، «أعوذ بالله من الشيطان الرجيم»، «أعوذ بالله السميع العليم…»،
  «بسم الله الرحمن الرحيم» — يُبتلع ولا يُعدّ خطأً في أول كلمة. يُقبل ناقصه
  أيضًا («بسم الله» ثم البدء)، ويُقبل «باسم» و«الرحمان». وإذا كانت البسملة هي
  الآية نفسها (الفاتحة) تُتبَّع كآية، ولا يُبتلع ما يطابق أول كلمة متوقّعة فعلاً
  (مثل «الله» في ٢:٢٥٥). ولا ينطبق هذا إلا قبل أول كلمة في الجلسة.
- **لا اتهام من أول كلمة غريبة:** الكلمة غير المطابقة الأولى تُعدّ ضجيجًا
  وتُهمَل؛ الثانية على التوالي تُعلَّم خطأً. وتجاوز كلمة إلى كلمة لاحقة لا يحدث
  إلا بمطابقة تامة، فالقفز لا يُبنى على تخمين.
- **الحروف المقطّعة:** تُكتب في المصحف كلمة واحدة («الٓمٓ»، «كٓهيعٓصٓ»، «يسٓ»)
  وتُتلى بأسماء الحروف («ألف لام ميم»، «كاف ها يا عين صاد»، «ياسين»). يعرف
  `src/lib/muqattaat.ts` موضع كل مجموعة، ويقرأ أسماء الحروف ويجمعها حتى تكتمل،
  فتُحتسب الكلمة **واحدة** لا ثلاثاً أو خمساً، ويُقبل أيضاً «الم» و«طاها» و«حاميم»
  كلمةً واحدة، والحروف المفردة («ا ل م»)، والاسم بتنوين («ألفاً لاماً ميماً»)،
  والشكل القريب للكلمة كلها («آلام»). ومحرّك المتصفح يكتب «ألف» رقمًا (`1000`)
  لأن الكلمة تعني الألف أيضًا، فيُعاد الرقم إلى «ألف» قبل المطابقة بدل أن يضيع.
  ترتيب خاطئ للأسماء لا يُقبل. وعندما يقف المؤشّر على الحروف تظهر في القارئ
  تلميحة **«تُقرأ: ألف لام ميم»** ليعرف القارئ الصيغة المتوقّعة بالضبط.
- **توجيه المحرّك بكلمات الآية:** حيث يدعم المتصفح تمرير عبارات مرجَّحة
  (`SpeechRecognitionPhrase` في Chrome 138+)، تُمرَّر **كلمات الآية القادمة فقط**
  بتعزيز متناقص: كلمتا المؤشّر بقوة ٨، ثم أربع بقوة ٥، ثم الباقي ٢. الغرض أن
  يُسمع «دهاقاً» و«ألف» كما هما لا أن يُخمَّن غيرهما؛ ولهذا لا يُرفع التعزيز إلى
  أقصاه، ولا تُمرَّر كلمة تجاوزها القارئ، ولا يفتح التوجيه كلمةً ولا يحرّك
  المؤشّر. المتصفحات التي لا تدعمه تعمل كما هي بلا توجيه.

### الأحكام في التتبّع

التطبيق لا يحكم على تجويدك — لا يسمع الفم ولا يقيس زمن الغنّة — لكنه لا يعاقبك
على النطق الصحيح للحكم. هذه هي الأحكام التي لا تُنتج أخطاءً كاذبة:

| الحكم | ما يقبله التتبّع |
|---|---|
| الإخفاء | التنوين نونًا («كاسن») أو محذوفًا («كاس») |
| الإدغام | نونًا صارت الحرف التالي («مر ربك»، «مرربك» مدموجة) |
| الإقلاب | نونًا وتنوينًا ميمًا («مم بعد»، «كاسم») |
| المدّ | زيادة حرف المدّ أو حذفه |
| القلقلة | لا تغيّر حروفًا، فلا أثر لها في المطابقة |
| اللام الشمسية | حذف لام التعريف («اشمس») |
| همزة الوصل والتسهيل | توحيد الألف والهمزة في التطبيع |
| الوقف | حذف التنوين أو حركة الآخر عند الوقوف |
| الغنّة | شدّة النون والميم تُطرح مع الحركات |

### الأخطاء لا توقف الجلسة

عند سماع كلمة مختلفة تُلوَّن الكلمة بالأحمر ويُصدر التطبيق نغمة تنبيه قصيرة،
ثم يستمر التتبّع. لا يتوقّف المؤشر ولا تنتظر الجلسة إعادة التلاوة. إذا أعدت
تلاوة الكلمة نفسها بشكل صحيح عادت إلى وضعها الطبيعي ونُقص عدّاد الأخطاء.
التكرار المتتالي للكلمة نفسها لا يُحتسب مرتين.

### حين يفقد التعرّف مكانه

اضغط أي كلمة في المصحف ثم **«تابع التتبّع من هذه الكلمة»**: ينتقل المؤشّر إلى
هذه الكلمة دون تسجيل خطأ ودون تغيير عدّاد الأخطاء. في وضع إخفاء الآيات تبقى
الكلمات المخفية قابلة للضغط لهذا الغرض فقط، وتُفتح بطاقة لا تكشف نصّ الكلمة
ولا سجلها — تذكر رقمها فقط. هذه هي الطريقة العملية لاستعادة المزامنة عندما
يخطئ محرّك المتصفح في موضعه، بدل الانتظار حتى يعود وحده.

### تصحيح الحركات (التشكيل)

عندما يعيد محرّك التعرّف كلمات مشكولة، يقارن التطبيق حركاتها بحركات المصحف
ويسجّل `tashkeel` إذا اختلفت الحركة مع بقاء الحروف. المقارنة لا تشترط تطابق
التشكيل الكامل: تُقارن فقط الحركات التي صرّح بها الطرفان، فغياب السكون أو
الشدة عند المحرّك ليس خطأً. تعرّف المتصفح المجاني يعيد الكلمات بلا حركات
عادةً، لذلك يبقى هذا الفحص تلقائياً حين تتوفر الحركات فقط، ولا يخمّن أبداً من
نص بلا تشكيل.

للتسجيل اليدوي أثناء التلاوة مسارَان:

- **زر «حركة»** في شريط الجلسة يسجّل الحركة الخاطئة على **آخر كلمة قرأتها**
  (وليس الكلمة التالية)، ولا يحرّك المؤشر ولا يوقف الجلسة.
- **بطاقة الكلمة**: اضغط أي كلمة قرأتها ثم «سجّل حركة خاطئة على هذه الكلمة»
  لتصحيح كلمة سابقة في أي وقت من الجلسة.

تُعلَّم الكلمة بالكهرماني وتُحتسب خطأً مرة واحدة فقط، وإعادة تلاوتها بالحركة
الصحيحة تُزيل الخطأ وتُنقص العدّاد.

### بداية الجلسة من آية محدّدة

قبل بدء الجلسة تختار الآية التي تبدأ منها. الآيات قبلها لا تُعرض ولا تدخل
قائمة الكلمات، فلا يمكن أن تُحتسب أخطاءً. ينتقل رابط الصفحة إلى آية البداية
(`?ayah=N`) وتبدأ الجلسة من أول كلمة فيها.

### إتمام الصفحة والانتقال إلى التالية

الصفحة خمس آيات. عند إتمام آخر كلمة فيها تنتقل الجلسة وحدها إلى الصفحة التالية
(`?ayah=` إلى الآية التالية لآخر آية)، وتبقى الجلسة مفتوحة والميكروفون يعمل،
وتظل الصفحة الجديدة مخفية كما بدأت. لا يُنهى التسجيل عند حدّ الصفحة، ولا يتوقّف
المؤشّر إلا إذا توقّف القارئ؛ وحينها ينتظر أول كلمة يتلوها. الكلمات التي
يسمعها المحرّك أثناء لحظة الانتقال تُحفظ وتُسلَّم إلى متتبّع الصفحة الجديدة،
فلا تضيع أول كلمة بعد الحدّ. وينتهي التسجيل وحده عند إتمام آخر صفحة في السورة.
سجل الجلسة يحفظ **آية البداية الأصلية** وآخر آية وصل إليها القارئ، لا آخر صفحة
فقط.

### التوقّف والعودة لموضع سابق

إذا توقّفت ثم بدأت التلاوة من كلمة سابقة، ينتظر التطبيق كلمتين متتاليتين
تطابقان الموضع السابق قبل تحريك المؤشر، لأن الكلمات المفردة تتكرّر كثيراً.
بعد التأكيد يعود المؤشر إلى موضع البداية، وتُعلَّم الكلمات المعادة صحيحة،
ويُزال الخطأ النشط عنها في الجلسة. بهذا لا تُحتسب إعادة التلاوة خطأً، وتُصحَّح
الكلمة التي أخطأت فيها سابقاً بمجرد إعادة تلاوتها.

إعادة تلاوة كلمة صحيحة داخل الجلسة نفسها تُزيل خطأها النشط من سجل الجلسة
(يمكن إرجاعه من سجل الكلمة).

إذا رُفض إذن الميكروفون أو لم يدعمه المتصفح أو تعذّر التعرّف، تظهر لافتة
توضّح ذلك، ويعمل التتبّع اليدوي فقط: خطوة واحدة لكل ضغطة. يمكن اختيار
المحرّك من الإعدادات أو من نافذة الموافقة الأولى.

التعرّف في المتصفح قد يعالج الصوت سحابياً لدى مزوّد المتصفح؛ التطبيق لا
يسجّل الصوت ولا يخزّنه، ولا يحفظ إلا الكلمات التي تعرّف عليها. وهو محرّك عامّ
غير مدرَّب على التلاوة، لذا قد يخطئ في موضعه أو يسمع كلمة قريبة؛ لهذا صار
التطبيق متسامحاً في المطابقة، ويعطيك «تابع التتبّع من هذه الكلمة» لتصحيح الموضع
بنفسك. المرحلة الثانية تستبدله بخدمة مفتوحة المصدر عبر WebSocket: رسائل `start`
/ PCM16 / `partial` / `word` / `stop`، مع ثقة لكل خطأ، ومواءمة قسرية على كلمات
الآية المتوقعة.

## أسئلة التجويد

صفحة `/tajweed` تضم ١٠ مراحل و١٠٣ أسئلة اختيار من متعدد في أحكام التجويد،
مأخوذة من لعبة «رحلة الإتقان في أحكام التجويد» التي أنشأها صاحب التطبيق
(`src/data/tajweed.ts`). كل جولة خمسة أسئلة تُخلط أسئلتها وخياراتها، ويظهر
شرح الإجابة بعد الاختيار. أفضل نتيجة لكل مرحلة تُحفظ محلياً في
`tadabbur.tajweed.v1`، ولا تُرسل إجابات إلى أي خادم.

## موسوعة الحديث

صفحة `/hadith` تضم ٦٤ حديثاً صحيحاً مختاراً في ١٢ باباً (الصلاة، الطهارة،
الصيام، الزكاة والصدقة، الحج، القرآن، الذكر والدعاء، الأخلاق، العلم، بر
الوالدين، المعاملات، الرقائق)، مأخوذة من **موسوعة الدرر السنية**
(<https://dorar.net/hadith>) مع الراوي والمصدر ورقم الحديث ودرجة الحديث كما
ذكرها المصدر، ورابط بحث كل حديث في الموسوعة.

- بحث فوري في النص والراوي والمصدر، وتصفية بالباب.
- حفظ الأحاديث في المفضلة محلياً في `tadabbur.hadith.v1`، ونسخ الحديث مع
  التخريج.
- البيانات في `src/data/hadith.ts`، ولا تُرسل أي طلبات إلى dorar.net من
  التطبيق وقت الاستخدام؛ الروابط تفتح في تبويب جديد.

## نسخة سطح المكتب

```bash
./scripts/package-desktop.sh
```

ينشئ `~/Desktop/تدبّر.app`: نسخة إنتاج مستقلة تخدم `dist/` على
`127.0.0.1:47821` وتفتحها في نافذة Chrome مستقلة بملف تعريف خاص، ليثبت إذن
الميكروفون وتبقى البيانات في أصل واحد. افتحه بالنقر المزدوج، وأغلق التطبيق
من Dock لإيقاف الخادم. إن لم يكن Chrome مثبتاً يُفتح المتصفح الافتراضي.

## النشر على GitHub Pages

كل دفع إلى `main` يشغّل `.github/workflows/deploy.yml`: يثبّت الحزم، يشغّل
الاختبارات، يبني الإنتاج، ثم ينشر `dist/` على GitHub Pages. الرابط الناتج:

<https://orabi20266.github.io/tadabbur-quran/>

لا حاجة إلى خادم أو قاعدة بيانات؛ كل شيء يعمل في المتصفح.

الصفحة تُخدم عبر service worker، فقد يظل المتصفح يعرض حزمة قديمة بعد النشر.
لذلك تُفعَّل `skipWaiting` و`clientsClaim`، ويتحوّل التطبيق وحده إلى النسخة
الجديدة عند فتحه من جديد، ويُعاد التحميل مرة واحدة عند تبديل العامل. وفي
**الإعدادات ← حول التطبيق** زر **«تحميل آخر نسخة»** يزيل عامل الخدمة وذاكرته
ويعيد التحميل من الشبكة دون مساس بالسجل، ويظهر بجانبه **رقم البناء** للتأكد من
النسخة التي تعمل فعلاً.
